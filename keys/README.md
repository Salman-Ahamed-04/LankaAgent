# SmartLanka API Keys Directory

You can upload or paste your API keys directly into this folder.

### Supported File Names:
- `gemini_api_key.txt` (or `api_key.txt` or any `.txt` file containing your key)

### Instructions:
Simply paste your Google Gemini API key as plain text inside `gemini_api_key.txt`.
SmartLanka will automatically read and load it into the AI Concierge on startup.
